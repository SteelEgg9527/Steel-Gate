# 钢铁之门 · 地图规划器使用说明

工具位置：

```text
tools/map-planner.html
```

本地访问：

```text
http://127.0.0.1:8790/tools/map-planner.html
```

它是一个独立的静态网页，不依赖游戏运行，也不修改游戏代码。

## 用途

用于在美术制作前，把“地图意图”画成可读的结构数据：

- 地形高低
- 水域、森林
- 公路、土路、桥梁
- 占领区
- 通讯塔、雷达站、港口、海岸基地
- 出生点
- 黄圈
- AI 进攻路线

最终导出 `map.json`，作为地图实现和后续地图导入器的输入。

## 游戏内使用

主菜单 → **自定义地图** → **新建地图**，会打开内置地图编辑器。

- 保存后只进入本机“自定义地图”列表，不会进入正式地图池。
- 可以选“混战”或“防御”直接游玩。
- “导出地图文件”生成 `.steelmap.json`，可交给作者审核是否收录为正式地图。
- “导入地图文件”可导入别人发来的 `.steelmap.json`。
- 自定义地图保存在浏览器 `localStorage`，换浏览器或清缓存会丢失；重要地图请导出文件备份。

当前游戏内自定义地图支持：

- **2000m 陆战**
- **5000m 海战**

海战地图的海岸线由规划器中的水域自动生成：把水域画在**地图右侧**，系统取水域左边缘作为海岸线，左侧为陆地、右侧为海洋。

海战当前只支持单一海岸线，不支持多岛屿、内海或复杂水网；可在陆地上放置通讯塔、雷达、港口、海岸炮台，再用“舰炮轰鸣”或“背水一战”游玩。

## 基本操作

1. 上传手绘草图或参考图；参考图只是底图，不写入 `map.json`。
   - 滚轮缩放画布，中键/右键拖动画布，右下角“适应”恢复全图。
   - 先选“模式”，再选尺寸：陆战固定 2000m，海战固定 5000m。
   - 点击“移除参考图”可立即清除底图。
   - 重新导入 JSON 时也会清除当前参考图，避免套用旧底图。
2. 选择模式：陆战 / 海战；尺寸由模式自动固定为 2000m / 5000m。
3. 用“抬高地形 / 压低地形”刷出高地、山脊、洼地。
4. 用水域、森林笔刷画地形。
5. 公路、土路、AI 路线：
   - 连续点击添加路径点
   - 按 Enter 或点击“完成路线”结束
6. 放置占领区、通讯塔、雷达站、港口、海岸基地、出生点、黄圈。
7. 点击“导出 map.json”。

选择与编辑：

- 选择“选择 / 编辑”工具
- 点击对象选中
- 拖动对象移动
- 圆形对象拖动右侧方点调整半径
- 道路/AI 路线拖动路径点，拖动线身整体移动
- 按 Delete 或“删除选中”清除
- 橡皮擦可整条删除道路、AI 路线，也可删除桥梁、水域、森林、站点等

鼠标移动时会显示当前笔刷/对象半径。

## 重要约定

- 坐标原点在左上角。
- x 向右，y 向下。
- 所有坐标单位是米。
- 地图为正方形。
- 高度值范围：0（最低）到 1（最高）。
- 高度网格默认 128×128。
- 道路路径点按顺序连接。
- 桥梁是一个独立点位。
- AI 路线用于规划进攻方向，不是实际寻路结果。

## 绘制建议

### 地形

- 高地不要画成孤立圆点，尽量形成连续山脊。
- 山脊作为视线遮挡和射程优势。
- 洼地可以作为隐蔽接近路线。
- 缓坡不要过陡，否则车辆寻路会绕行。

### 道路

- 公路优先连接出生点、主要据点、桥梁。
- 土路作为次级机动路线。
- 道路不要直接穿过多单位争夺点，可以在附近绕行。
- 桥梁应连接两岸道路。

### 据点

- 工事放在道路交汇、高地、桥头。
- 村庄放在道路节点。
- 灌木、森林放在侧翼和隐蔽接近路线。
- 通讯塔、雷达站、港口、海岸基地按海战逻辑放置。

### AI 路线

AI 路线用于表达“希望 AI 主要从哪边来”，不是最终寻路。实际单位仍会通过可通行网格寻路，路线上有障碍时会绕行。

## 导入到游戏

已提供转换器：

```bash
node tools/map-plan-to-map.js plan.json > js/maps-plan.js
# 陆战与海战规划文件均支持
```

`index.html` 已预留：

```html
<script src="js/maps-plan.js"></script>
```

转换后会生成一个 `plan_<名称>` 地图，可从地图选择中进入。

当前已接入：

- 高度网格
- 道路
- 林地
- 占领区
- 站点
- 出生点
- 黄圈
- AI 路线
- 水域阻挡
- 桥梁跨水
- 非步兵道路寻路与道路速度

尚未完全接入：

- 水面海岸线精细生成
- 多桥梁连通性校验
- 高地 LOS 遮挡
- 全局地形成本 A* 的最终平衡
