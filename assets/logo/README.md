# 钢线 1944 · LOGO 素材

## 文件

| 文件 | 用途 |
|---|---|
| `sightmark.svg` | 主菜单瞄具标志，透明背景，纯矢量 |
| `sightmark-preview.png` | 瞄具标志深色背景预览 |
| `logo-lockup.svg` | 瞄具 + STEEL LINE / 钢线 1944 铭牌组合 |
| `logo-lockup-preview.png` | 完整标志深色背景预览 |
| `brand-mark.svg` | 左上角品牌菱形标记 |
| `favicon-64.png` | 当前游戏 favicon |

## 瞄具标志

- 源画布：`300 × 300`
- 透明背景
- 无内部文字
- 保留主菜单的双层外圈、顶部指针、左右密位点、下方双排箭头、中心准星
- 金色元素：`#e6d6a4` / `#ead9a8`
- 冷绿色刻度：`rgba(198,224,207,0.80)` 系

## 完整组合标志

- 源画布：`520 × 560`
- 瞄具在画布上方
- 铭牌由矢量多边形构成
- `STEEL LINE` 使用等宽字体
- `钢线 1944` 使用中文无衬线字体

注意：完整组合里的文字使用 `<text>` 字体渲染，不同系统字体可能略有差异。  
需要跨平台完全一致时，优先使用 PNG，或把文字转成路径。

## favicon
