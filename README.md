# 钢线 1944 · STEEL LINE

一款直接运行在浏览器里的二战 RTS。

指挥步兵、装甲、火炮和舰队，在三方混战中争夺阵地，守住自己的防线。

## 在线游玩

**https://www.steelline1944.top/**

推荐使用 Edge / Chrome 桌面浏览器。

---

## 游戏模式

- **三军混战**：三方争夺占领区，按战功和阵地决出胜负。
- **背水一战**：守住防线，抵挡一波接一波的进攻。
- **舰炮轰鸣**：5km 海陆战场，多张登陆地图，争夺海岸、雷达和通讯站，召唤战列舰提供火力支援。

## 基本操作

| 操作 | 说明 |
| --- | --- |
| 左键 | 选择单位、拖框多选 |
| 右键 | 移动、攻击或占领 |
| Shift + 右键 | 使用当前单位的特殊指令 |
| 空格 | 暂停 / 继续 |
| F | 停止当前舰船指令 |
| 鼠标滚轮 | 缩放视角 |
| 小地图 | 点击跳转视角，右键下达移动命令 |
| 编组 | 选中部队后点击部队清单下方的“+”；点击编组可快速选中 |

选中单位后，右侧面板会显示可用技能、装备和状态。

## 战场系统

- 连队升级后可以抽卡，获得单位、装备或支援。
- 步兵可以携带多种装备，工程车可以布雷、架设铁丝网和拒马。
- 占领工事区后可以部署强化工事，工事会自动索敌开火。
- 补给点、侦察和火力支援能够改变战场局势。
- 舰炮轰鸣模式可以召唤战舰，使用主炮、副炮和防空火力支援登陆作战。

## 存档与设置

- 无尽模式支持战斗中存档和读取。
- 主界面和局内共用同一份设置，修改后即时生效。
- 设置中可开启自动界面缩放，或手动调整界面大小。
- 排行榜显示本机最近的对局战绩。

## 运行

- 在线版打开网页即可游玩。
- 下载版解压后双击 `开始游戏.cmd` 启动。
